# protocol

Esta extensión proporciona un sistema para interactuar con el protocolo de sincronización del juego y ampliarlo.

El juego funciona como una simulación. En multijugador, cada participante ejecuta su propia simulación. Casi toda la comunicación pasa por un protocolo que garantiza que los cambios, como colocar un edificio, se aplican en todas las máquinas exactamente en el mismo instante, o tick de juego.

La documentación está disponible [aquí](https://gynt.github.io/ucp-extension-protocol).
