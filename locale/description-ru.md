# protocol

Это расширение предоставляет систему для взаимодействия с протоколом синхронизации игры и его дополнения.

Игра работает как симуляция. В сетевой игре каждый участник выполняет собственную симуляцию. Почти весь обмен данными проходит через протокол, который обеспечивает применение изменений, например размещения здания, на всех компьютерах в один и тот же игровой такт.

Документация доступна [здесь](https://gynt.github.io/ucp-extension-protocol).
