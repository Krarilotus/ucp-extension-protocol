# protocol

Ez a bővítmény a játék szinkronizációs protokolljának használatához és bővítéséhez biztosít rendszert.

A játék szimulációként fut. Többjátékos módban minden résztvevő saját szimulációt futtat. A résztvevők közötti kommunikáció szinte teljes egészében olyan protokollon keresztül történik, amely biztosítja, hogy az épületek elhelyezéséhez hasonló változások minden gépen pontosan ugyanabban a játékütemben történjenek.

A dokumentáció [itt](https://gynt.github.io/ucp-extension-protocol) található.
