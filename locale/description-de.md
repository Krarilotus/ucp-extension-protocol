# protocol

Diese Erweiterung stellt ein System bereit, um mit dem Synchronisationsprotokoll des Spiels zu arbeiten und es zu erweitern.

Das Spiel läuft als Simulation. Im Mehrspielermodus führt jeder Teilnehmer seine eigene Simulation aus. Fast die gesamte Kommunikation zwischen den Teilnehmern erfolgt über ein Protokoll, das sicherstellt, dass Änderungen wie das Platzieren eines Gebäudes auf allen Rechnern zum exakt gleichen Spieltick erfolgen.

Die Dokumentation ist [hier](https://gynt.github.io/ucp-extension-protocol) zu finden.
