# protocol

Cette extension fournit un système pour interagir avec le protocole de synchronisation du jeu et l’étendre.

Le jeu fonctionne comme une simulation. En multijoueur, chaque participant exécute sa propre simulation. Presque toutes les communications passent par un protocole garantissant que les changements, comme la construction d’un bâtiment, sont appliqués au même instant précis, au même tick de jeu, sur chaque machine.

La documentation est disponible [ici](https://gynt.github.io/ucp-extension-protocol).
